# 背景
本仓库已有一套成熟的「plans + todos」拆分约定：
- 计划文件目录 docs/plans/，文件名 `description-of-the-plan-YYYY-MM-DD.md`，一任务一文件，互不重名；

- docs/todo.md 以拓扑顺序的表列出全部任务，字段为：序号 / Task ID / 标题（英文短名）/ blockedBy / 状态 / 验收要点（摘要）/ 计划文件，并附「拓扑顺序注释」与「交付物核对」两节。
日期统一用今天 2026-08-31，按上述格式就地延续。

本次要拆解的源文档是 docs/feat-icewash.md —— 「冰洗预测模型接入通用智能体框架 · 最终方案」，是比现有 T49~T58 更新、更完整的口径。

# 边界与异常处理
